# Campus Library & Life Super App - Project Features

## Core Goal: Library Seat Finding
The primary objective of the application is to solve the problem of students finding empty seats in the university library. 
*   **Library Floor Plans:** We will map out all the floors of the university library and integrate these floor plans into the application. Since this is our main goal, the user interface is designed so that students can easily access and use this service.
*   **QR Code Seat Check-in:** To indicate that they are occupying a seat, students will be required to scan a QR code located at their desk. This will verify their seating status in real-time.

## Additional Features

### 1. Library Book Services
*   Students will be able to easily buy, donate, or rent books directly through the application.

### 2. University Clubs and Events
*   Students will be able to observe the active clubs present at the university.
*   They can browse upcoming events, join them through the app, and provide suggestions/feedback regarding the events.

### 3. Internship Opportunities
*   The application will provide students with information regarding internship opportunities, specifically based in the province where the university is located.

### 4. Roommate Finder
*   Students will be able to search for and find a roommate using a dedicated feature within the application.
